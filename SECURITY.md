# Security policy

## Supported version

Security fixes target the latest released version of PageWand.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository: open the repository's **Security** tab, choose **Advisories**, then **Report a vulnerability**.

Do not open a public issue with exploit details, sensitive page content, credentials, or private URLs. Include clear reproduction steps, impact, the affected version, and any suggested mitigation in the private report.

Private vulnerability reporting must be enabled before this repository is made public. Until that launch gate is complete, security reports should not be solicited publicly.
